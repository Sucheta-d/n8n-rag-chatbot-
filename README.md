# AI RAG Chatbot with n8n

## Features
- Google Drive document ingestion
- OpenAI embeddings
- Pinecone vector database
- AI Agent with memory
- Chat-based RAG retrieval

## Workflow Architecture

Google Drive → Embeddings → Pinecone → AI Agent

## Tech Stack
- n8n
- OpenAI
- Pinecone
- Google Drive

## Setup

1. Import workflow JSON into n8n
2. Configure credentials:
   - OpenAI
   - Pinecone
   - Google Drive
3. Execute ingestion workflow
4. Start chat trigger
